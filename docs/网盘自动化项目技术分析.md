### 3.2 TgtoDrive 架构

### 6.2 技术选型建议

#### 季集解析正则

```python
import re

patterns = [
    r'[Ss](\d+)[Ee](\d+)',              # S01E01
    r'第(\d+)季第(\d+)集',               # 第1季第1集
    r'[Ee][Pp]?(\d+)',                   # EP01, E01
    r'第(\d+)集',                         # 第01集
    r'Season\s*(\d+)\s*Episode\s*(\d+)', # Season 1 Episode 1
]

def parse_episode(filename):
    for pattern in patterns:
        match = re.search(pattern, filename, re.IGNORECASE)
        if match:
            groups = match.groups()
            if len(groups) == 2:
                return int(groups[0]), int(groups[1])
            elif len(groups) == 1:
                return 1, int(groups[0])
    return None, None
```


## 七、风险与注意事项

### 7.1 法律风险

- 网盘API逆向可能违反服务条款
- 自动转存涉及版权内容需谨慎
- 建议仅用于个人学习研究

### 7.2 技术风险

| 风险 | 说明 | 应对 |
|------|------|------|
| API变更 | 网盘API可能随时变更 | 模块化设计，便于快速适配 |
| 封号风险 | 频繁请求可能被限制 | 添加请求间隔、使用代理 |
| Cookie失效 | 需要定期刷新 | 实现自动刷新机制 |
| 验证码 | 登录时需要验证码 | 接入打码平台或手动处理 |

## 八、总结

### TgtoDrive 优势

- 功能最完整，覆盖全流程
- 支持STRM生成和Emby 302播放
- 多网盘支持（115/123/光鸭/天翼）
- 智能整理和洗版功能强大
- 有详细的Web管理界面

### Symedia 优势

- 插件化架构，扩展性好
- 支持夸克和阿里云盘
- 字幕处理功能完善
- 代码结构清晰（虽然加密）

### 追影项目建议

1. **优先实现基础转存**：先支持123网盘（API简单），再扩展其他网盘
2. **采用插件架构**：便于后续添加新网盘和功能
3. **重视季集解析**：这是剧集自动化的核心
4. **做好错误处理**：网盘API不稳定，需要完善的重试机制
5. **考虑合规性**：明确功能定位，避免法律风险
