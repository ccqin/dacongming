## 一、项目现状

### 1.1 项目概述
**追影 (Zhuiying)** 是一个影视数据聚合平台，基于 .NET 10 构建的微服务架构。

**当前运行的服务**:
- `zhuiying-hub` (端口 5002): 统一数据 Hub，代理 TMDB API + SQLite 缓存
- `zhuiying-mainsite` (端口 5000): Blazor WASM 前端主站
- `pansou` (端口 8889): 网盘资源搜索引擎

**访问地址**:
- 主站: https://zhuiying.19856789.xyz
- Hub API: https://zhuiyinghub.19856789.xyz

### 1.2 技术栈
- **后端**: .NET 10, ASP.NET Core, Minimal APIs
- **前端**: Blazor WebAssembly, MudBlazor 7.15.0
- **数据库**: SQLite
- **部署**: Docker Compose, 1Panel (Nginx 反代)
- **CDN**: Cloudflare

## 三、网盘转存功能计划

### 3.1 总体目标
实现影视资源的自动搜索、转存到用户网盘，并记录已转存的季集信息。

### 3.2 功能需求
1. **网盘账号管理**: 添加/删除网盘账号，支持多种网盘类型
2. **手动转存**: 从搜索结果选择资源转存到指定网盘
3. **自动转存**: 定时检查收藏的影视，自动搜索并转存
4. **季集记录**: 记录已转存的季集，避免重复转存
5. **智能选择**: 根据画质、字幕偏好选择最佳资源

### 6.4 季集解析正则

```csharp
public class EpisodeParser
{
    private static readonly Regex[] SeasonEpisodePatterns = new[]
    {
        new Regex(@"[Ss](\d+)[Ee](\d+)", RegexOptions.Compiled),           // S01E01
        new Regex(@"第(\d+)季第(\d+)集", RegexOptions.Compiled),            // 第1季第1集
        new Regex(@"[Ee][Pp]?(\d+)", RegexOptions.Compiled),                // EP01, E01
        new Regex(@"第(\d+)集", RegexOptions.Compiled),                      // 第01集
        new Regex(@"Season\s*(\d+)\s*Episode\s*(\d+)", RegexOptions.Compiled | RegexOptions.IgnoreCase)  // Season 1 Episode 1
    };
    
    private static readonly Regex QualityPattern = new Regex(
        @"(4[Kk]|2160[pP]|1080[pP]|720[pP]|480[pP])", 
        RegexOptions.Compiled);
    
    public EpisodeInfo Parse(string fileName)
    {
        var info = new EpisodeInfo();
        
        // 解析季集
        foreach (var pattern in SeasonEpisodePatterns)
        {
            var match = pattern.Match(fileName);
            if (match.Success)
            {
                var groups = match.Groups;
                if (groups.Count >= 3)
                {
                    info.Season = int.Parse(groups[1].Value);
                    info.Episode = int.Parse(groups[2].Value);
                }
                else if (groups.Count >= 2)
                {
                    info.Season = 1;
                    info.Episode = int.Parse(groups[1].Value);
                }
                break;
            }
        }
        
        // 解析画质
        var qualityMatch = QualityPattern.Match(fileName);
        if (qualityMatch.Success)
        {
            info.Quality = qualityMatch.Groups[1].Value.ToLower();
        }
        
        return info;
    }
}
```
